This branch contains the pre-compiled, production-optimized static deployment package for ELITE Architectural Wood Engineering (Design 2), pre-configured with `basePath: /elite-design-2` for direct hosting under `https://apex-agency.tech/elite-design-2/` (or any domain on the host).

## Target Server Deployment

- Live URL: `https://apex-agency.tech/elite-design-2/`

## Deployment Instructions on cPanel:
